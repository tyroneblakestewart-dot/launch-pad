# design/

Design reference. Nothing here is served, imported or bundled by the app.

- `token-page-v2/` — the token page: target layout, build states, the data
  inventory (which doubles as the backend mapping) and the style spec.
- `app-pages/` — the rest of the app as drawn in the Claude Design tool and
  handed over 4 Sep 2026: studio, Social Studio, Hoodchat, plans. Read
  `app-pages/design-vs-live.md` first — the live look wins wherever the two
  disagree, and that file lists every difference.
- `free-site-template-source.html` (in `docs/`, not here) is the free-site
  template and IS used at build time — it is not a reference file.
